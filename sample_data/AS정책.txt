AS 및 품질보증 정책

AS(After Service) 정의:
구매 후 상품 사용 중 발생한 문제를 무상/유상으로 수리 또는 교체해주는 서비스입니다.

AS 보증 기간:
- 기본 보증기간: 구매 후 1년
- 상품 유형별 상이할 수 있음
- 배송 완료일부터 계산

AS 대상 상품:
1) 전자제품 (1년 무상 AS)
   - 스마트폰, 태블릿, 노트북
   - TV, 카메라, 이어폰
   - 모니터, 키보드, 마우스
   - 배터리/충전기

2) 의류/신발 (3개월 무상 AS - 제조 결함만)
   - 솔/힐 분리
   - 지퍼 고장
   - 바느질 불량
   - 염색 불균일 (반품 권장)

3) 가구/인테리어 (1년 무상 AS - 조립/설치 문제만)
   - 조립 불량 지원
   - 설치 관련 문제
   - 부품 누락시 재배송

4) 화장품/식품 (AS 불가)
   - 소비기한 관련 교환/환불은 반품정책 참고
   - 개봉 상품 AS 불가

AS 신청 방법:
1. 고객센터 전화
   - 전화: 02-XXXX-XXXX
   - 평일 09:00-18:00, 토 10:00-16:00
   - 상담사가 증상 파악 후 AS 진행

2. 온라인 신청
   - 마이페이지 → "AS 신청"
   - 상품 선택 → 증상 설명 → 사진 첨부
   - 2시간 내 답변

3. 방문 수리
   - 서울/경기: 직영 A/S센터 방문 가능
   - 기타 지역: 택배로 배송 후 수리

AS 신청 시 필요 정보:
- 주문번호
- 상품 구매 날짜
- 발생한 문제 상세 설명
- 증상 사진/동영상 (선택)
- 현재 상품 상태

무상 AS 대상:
1) 제조 결함
   - 공장 출고 당시 결함
   - 정상 사용 중 발생한 결함
   - 사용설명서 위반 아님

2) 자연스러운 성능 저하 (보증 기간 내)
   - 배터리 성능 저하 (1년 내)
   - 화면 번인/색감 변화 (품질 범위 초과)
   - 접점 부식/산화

3) 불량 배송
   - 배송 중 손상
   - 잘못된 상품 배송
   - 부품 누락

유상 AS 대상:
1) 고객 과실로 인한 손상
   - 낙하/충격으로 인한 파손
   - 액체 유입/습기 손상
   - 개조/분해로 인한 손상
   - 사용설명서 미준수

2) 정상 마모
   - 버튼 누르느라 벗겨짐
   - 케이스 긁힘
   - 배터리 자연 감소 (2년 이상)

3) 보증 기간 경과 후
   - 부품 가격 + 기술료
   - 수리 불가능 시 유상 교체

AS 절차:

무상 AS 진행:
신청 → 상담 → 수리/교체 결정 → 택배 수령 → 수리 (3-7일) → 반송

유상 AS 진행:
신청 → 상담 → 견적 안내 → 비용 동의 → 수리 진행 → 비용 청구 후 반송

수리 기간:
- 단순 소프트웨어 문제: 1-2일
- 부품 교체: 3-5일
- 복잡한 수리: 5-7일
- 부품 미재고시: 추가 1-2주

AS 배송:
- 무상 AS: 편도 무료 (수리 후 반송비 무료)
- 유상 AS: 양방향 배송료 고객 부담 (2,500원 x 2)

AS 관련 문의:
- 전화: 02-XXXX-XXXX
- 이메일: as@example.com
- AS 센터: 서울 강남구, 경기 수원시 (직영)

AS 불가능한 경우:
1) 보증 기간 경과 (1년 초과)
2) 물, 습기에 의한 손상
3) 불에 의한 손상
4) 개조/개인 수리 흔적
5) 제조사 내부 봉인 제거
6) 사용설명서 위반 사항
7) 정상적인 마모 (2년 이상)
8) 화장품, 식품 등 소비 상품
9) 소프트웨어 업데이트 거부 시 호환성 문제
10) 타사 제품과의 호환성 문제

특수 상황 처리:

지연 배송:
- AS 기간 중에는 보증 기간 연장 안 함
- 수리 완료 후 최대 2주 이내 배송

해외 구매자:
- 국내 배송지 필수
- 반송 배송료는 고객 부담
- A/S 기간 계산은 동일

기타:
- 개인정보 보호: AS 신청 시 정보 암호화 저장
- 스팸/악용 방지: 비정상적 AS 신청 시 거부 가능
- 환불 vs AS: 고객이 선택 가능 (14일 이내)
