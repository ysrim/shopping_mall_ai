결제정책

결제 수단:
1) 신용카드
   - 모든 카드사 지원 (국내 발급 필수)
   - 선불/후불 모두 가능
   - 일회성/정기 결제 가능
   - SSL 암호화 결제

2) 체크카드
   - 국내 발급 체크카드만 가능
   - 신용카드와 동일 혜택
   - 자동 이체 가능

3) 계좌이체
   - 우리은행, 신한은행, 농협, 국민은행, 하나은행, 광주은행, 전북은행 등
   - 실명 계좌 필수
   - 즉시 입금 (24시간 이내)

4) 휴대폰 결제
   - SKT, KT, LGU+ 지원
   - 월 한도: 통신사별 상이 (보통 300만원)
   - 문자 인증 필수

5) 포인트 결제
   - 보유 포인트로 결제 가능
   - 1포인트 = 1원
   - 부족분은 다른 결제 수단과 함께 사용 가능

할부 결제:
- 50,000원 이상: 2개월~24개월 할부 가능
- 신용카드사별 무이자 할부 이벤트 진행
- 무이자 할부: 수수료 없음 (카드사가 부담)
- 유이자 할부: 할부금액에 따라 이자 발생

결제 보안:
- 128bit SSL 암호화 적용
- 카드 정보는 서버에 저장 안 함
- 카드사 보안 서버에서 직접 처리
- OTP/보안카드 인증 지원

결제 절차:
1. 장바구니 → "결제하기" 클릭
2. 배송지 입력/확인
3. 결제 수단 선택
4. 결제 수단별 인증 (OTP, 카드 번호 등)
5. 최종 결제 완료
6. 주문 번호 발급
7. 배송 시작 (1시간 내)

결제 관련 주의사항:

신용카드:
- 한도 초과 시 결제 불가
- 도난 신고 카드로는 결제 불가
- 부정 거래 감지 시 카드사 승인 거부 가능

계좌이체:
- 오타 시 환불 처리 필요 (은행에서 처리)
- 야간(21:00 ~ 09:00) 이체 다음날 입금

휴대폰 결제:
- 월 한도 유의
- 유료 앱 구매 등과 통합 한도
- 미성년자 제약 (보호자 동의 필요)

결제 실패 원인:
1) 한도 초과 → 카드사 승인 불가
2) 잘못된 정보 입력 → 정보 재입력 필요
3) 카드 분실 신고 → 카드사 거부
4) 이중 결제 방지 → 같은 주문번호 재결제 불가
5) 보안 문제 감지 → 카드사 승인 거부

결제 취소:
- 결제 후 10분 이내 자동 취소 가능
- 10분 이후: 반품/환불 정책 참고

결제 영수증:
- 결제 완료 시 이메일로 전송
- 마이페이지 → "주문 조회" 에서 확인
- 세금계산서 발급 가능 (사업자)

결제 할인 및 이벤트:
- 신규 회원: 5,000원 쿠폰
- 생일 달: 3,000원 쿠폰
- 카드사별 할인: 신한카드 5% 할인 (매주 목요일)
- 휴일 이벤트: 주말 구매 시 포인트 2배 적립

결제 안전 정보:
- 공용 PC에서는 자동 로그인 해제 후 사용
- 결제 정보 입력 시 화면 가림 사용
- 정기 결제 설정 시 주의 (해지 시 24시간 소요)
- 피싱 메일/문자 주의 (절대 클릭 금지)
