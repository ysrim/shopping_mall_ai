배송정책

배송 기간:

일반 배송:
- 배송 기간: 2-3일 (주중 기준)
- 주말/공휴일 제외
- 야간 배송 불가 (새벽 6시 ~ 오전 9시)

당일배송:
- 지역: 서울/경기만 가능
- 조건: 오후 2시 이전 주문
- 배송비: 3,000원 (추가 요금)
- 배송 시간: 당일 저녁(6시~10시)

제주/도서산간:
- 배송 기간: 3-5일 추가 소요
- 배송비: 기본료 2,500원 + 추가 5,000원
- 산간벽지는 배송 불가능할 수 있음

배송비:

배송비 계산:
- 30,000원 이상 주문: 무료
- 30,000원 미만: 2,500원
- 제주/도서산간: 5,000원 추가
- 서울 근처 당일배송: 3,000원
- 산간벽지: 별도 문의 필요

무료 배송:
- 30,000원 이상 구매 시 자동 적용
- GOLD/PLATINUM 등급: 추가 무료배송 쿠폰 제공
- 특정 상품 지정: 무료배송 상품 별도 표시

배송 추적:

배송 정보 제공:
- 배송장번호는 주문 후 1시간 이내 제공
- SMS/이메일로 자동 안내됨
- 배송 상태는 실시간으로 확인 가능
- 배송 완료 후 2시간 내 알림

추적 방법:
- 마이페이지 → "주문 조회"
- 배송장번호로 택배사 홈페이지 확인
- SMS/이메일 링크 클릭
- 카카오톡 배송 알림

배송 관련 유의사항:

배송 불가 지역:
- 산간벽지 (일부)
- 섬 지역 (제주도 제외)
- 군부대, 교도소 등 특수시설
- 해외 주소

배송 시간 제약:
- 주말/공휴일은 배송 없음
- 야간 배송 불가 (새벽 6시 ~ 오전 9시)
- 특정 상품은 택배사 제약으로 배송 불가능할 수 있음
- 주소 오류로 인한 반송비는 고객 부담

배송 주소 변경:

변경 가능 시기:
- 배송장번호 발급 전: 마이페이지에서 자유롭게 변경
- 배송장번호 발급 후: 고객센터로 연락 필수 (가능한 범위 내만 변경)

변경 방법:
1. 배송장번호 발급 전
   - 마이페이지 → "주문 조회" → "배송지 변경"

2. 배송장번호 발급 후
   - 고객센터(02-XXXX-XXXX) 전화
   - 가능한 범위 내에서만 변경 가능
   - 지역 변경은 반송 후 재배송 필요

배송 지연 및 문제:

배송 지연 원인:
- 날씨(눈, 태풍 등)
- 택배사 물량 과다
- 지역 배송 혼잡
- 주소 오류로 인한 반송

배송 지연 시 조치:
1. 배송 추적 → 현재 위치 확인
2. 지연 사유 파악 (배송장번호로 조회)
3. 1-2일 추가 대기
4. 여전히 도착 안 하면 고객센터 문의

배송 안 된 상품:
- 배송 받지 못함
- 배송을 받았지만 분실
- 상품 외부 손상

조치 방법:
- 고객센터에 신고 (02-XXXX-XXXX)
- 배송장번호와 상세 상황 설명
- 택배사에서 역추적
- 분실 확정 시 재배송 또는 환불

배송 중 손상:

손상 확인:
- 수령 당시 외부 포장 손상 확인
- 상품 손상 시 즉시 고객센터 신고
- 증거 사진 촬영 (외부/내부 손상)

처리 방법:
- 상품 불량: 무료 반품/교환
- 배송사 과실: 배송사 배상 청구
- 고객 과실: 고객 책임 (배송 보험 활용)

반송 배송:
- 손상/오류: 무료 반송 배송비 제공
- 고객 과실: 배송료 2,500원 차감

배송 거부/거부 불가:

배송 거부 가능 시점:
- 배송 전 (배송장번호 발급 전)
- 배송 중 (일부 택배사 지원)

배송 거부 시 처리:
- 상품 반송
- 배송료 환급 (구매자 부담 배송료는 차감)
- 환불 처리 (2-3일)

배송 거부 불가:
- 배송 완료 후
- 상품 수령 후
- 이 경우 반품 정책 적용

특수 배송:

선물 배송:
- 다른 주소로 배송 가능
- 영수증 동봉 여부 선택
- 선물 메시지 추가 가능

정기 배송:
- 월 1회, 월 2회 등 설정 가능
- 배송 주기 변경 가능
- 일시 중단/재개 가능
- 언제든 정기 배송 취소 가능

해외 배송:
- 현재 지원하지 않음
- 국내 배송지 필수

배송 보험:

택배 배송 보험:
- 운송중 손상/분실 보험
- 배송 시 선택 가능 (추가료 약 1,000원)
- 배송사 과실로 인한 손상 시 보상

고객센터:

- 이메일: shipping@example.com
- 채팅상담: 홈페이지 우측 하단
- 실시간 배송 추적: 마이페이지 → "주문 조회"
