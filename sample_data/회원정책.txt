회원정책

회원 등급:
1) SILVER (실버)
   - 구매 금액: 0 ~ 100만원
   - 혜택: 5% 포인트 적립, 생일 3,000원 쿠폰
   - 배송비 할인: 1,000원

2) GOLD (골드)
   - 구매 금액: 100만원 ~ 300만원
   - 혜택: 7% 포인트 적립, 생일 5,000원 쿠폰, 월 1회 배송비 무료
   - 배송비 할인: 2,000원
   - VIP 고객 전담

3) PLATINUM (플래티넘)
   - 구매 금액: 300만원 이상
   - 혜택: 10% 포인트 적립, 생일 10,000원 쿠폰, 모든 배송비 무료
   - 배송비 할인: 전액 무료
   - VIP 고객 전담, 우선 상담

회원등급 확인 방법:
- 마이페이지 → "회원 정보" → "회원등급 확인"
- 매월 1일 자동 갱신
- 연간 구매액 기준으로 재산정

등급 혜택 변경:
- 기존 등급 혜택은 다음 달 1일부터 적용
- 상향된 등급도 다음 달 1일부터 적용
- 하향된 등급은 즉시 적용

포인트 시스템:

포인트 적립:
- 구매 금액의 1~2% 자동 적립 (등급별 상이)
- 배송 완료 후 적립
- 환불 시 차감
- 만료 기한: 적립 후 3년

포인트 사용:
- 1포인트 = 1원으로 사용 가능
- 구매 시 결제 시 사용
- 최소 사용 금액: 1,000포인트 이상
- 포인트만으로 구매 가능
- 환불 시: 포인트로 받거나 현금 환불 선택

포인트 불가 상품:
- 일부 특가/세일 상품
- 선물 카드
- 포인트 차감 상품

회원 정보 관리:

이메일 변경:
- 마이페이지 → "회원 정보" → "이메일 변경"
- 신 이메일 인증 필수
- 인증 후 즉시 변경

비밀번호 변경:
- 마이페이지 → "회원 정보" → "비밀번호 변경"
- 현재 비밀번호 입력 필수
- 새 비밀번호: 8~15자, 특수문자 포함 권장

비밀번호 분실:
- 로그인 페이지 → "비밀번호 찾기"
- 등록된 이메일 인증 필수
- 임시 비밀번호 이메일 발송
- 신 비밀번호로 변경 필수 (다음 로그인 시)

배송지 관리:
- 최대 10개 배송지 등록 가능
- 기본 배송지 설정 가능
- 주소 검색 기능 제공
- 수정/삭제 가능

개인정보 보호:

수집 정보:
- 필수: 이메일, 비밀번호, 이름, 휴대폰
- 선택: 생년월일, 성별, 기본 주소

정보 사용 목적:
- 구매 및 배송 처리
- 고객 상담 및 불만 처리
- 마케팅 (동의 시에만)
- 통계 분석

정보 보호 방법:
- 개인정보는 암호화 저장
- 내부 보안 정책 준수
- 정기적인 보안 감시
- 제3자 제공 금지 (동의 시 제외)

회원 탈퇴:
- 마이페이지 → "회원 정보" → "회원 탈퇴"
- 보유 포인트: 소멸 (환금 불가)
- 구매 내역: 조회 가능 (개인정보 일부 삭제)
- 탈퇴 후 30일 이내 재가입 불가
- 탈퇴 후 개인정보는 30일 후 삭제

회원 혜택:

쿠폰:
- 신규 회원: 5,000원 할인쿠폰
- 생일 달: 3,000원 쿠폰
- 등급별: 추가 할인쿠폰
- 이메일 뉴스레터: 정기적으로 제공

생일 축하:
- 생일 달에 자동 발송
- 3,000원 할인쿠폰
- 유효 기간: 30일

이메일 뉴스레터:
- 신상품 정보
- 할인 이벤트
- 계절 상품 추천
- 구독/구독 해제 자유 선택

SNS 팔로우 혜택:
- 인스타그램: 팔로우 시 2,000포인트
- 페이스북: 좋아요 시 1,000포인트
- 유튜브: 구독 시 3,000포인트

회원 등급 관리:

등급 산정:
- 연도별 구매액 누적
- 환불액은 차감
- 매년 1월 1일 기준으로 재산정
- 유지 기간: 1년 (다음 연도까지)

등급 하락:
- 연간 구매액 미달 시 자동 하락
- 예: GOLD (100만원) 미충족 → SILVER로 하락
